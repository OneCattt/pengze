# 茶室素材叠图预览

以用户提供的五张原始图片制作独立视觉预览，入口为 `index.html`。可切换“牌局排版”和“纯素材叠图”。此页不是可玩游戏，25张牌只作排版示意，倒计时固定为20秒。

- `source/` 保存用户提供的原始PNG；四张人物和牌桌素材具有真实Alpha通道。
- `assets/` 保存去除外侧低透明杂点并裁去透明留白的预览图。人物、牌桌无损保存为WebP；背景使用质量90的WebP。
- 透明度不超过8/255的像素清零，以16/255有效轮廓加4像素边距裁切；不对人物内容重新生成或涂改。
- `asset-manifest.json` 记录原始尺寸、文件指纹、透明度范围、裁切位置与预览文件。
- 头像信息、牌面、叫分和倒计时均为独立HTML排版。当前未接入实际游戏；33张扣底、选牌、出牌与微信真机适配仍需后续验证。

人物和牌桌的比例、遮挡先以本次预览评审为准。原始素材来源为本次用户上传，不以此次视觉检查代替生成工具的授权确认。
